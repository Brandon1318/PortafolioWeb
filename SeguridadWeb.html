Apoyo a la Seguridad Web

Este proyecto se enfocó en la investigación, documentación y práctica de herramientas de ciberseguridad utilizadas en auditorías técnicas y pruebas controladas. El objetivo fue comprender cómo se aplican distintas herramientas de Ethical Hacking para identificar vulnerabilidades, analizar riesgos y proponer medidas de mitigación en entornos Linux.

Durante el desarrollo se trabajaron fases como reconocimiento, escaneo de servicios, análisis de vulnerabilidades, pruebas de seguridad web y evaluación de mecanismos de autenticación. Para ello, se utilizaron herramientas como Nmap, Nessus Essentials, SQLMap, Metasploit Framework, John The Ripper, Hashcat y Hydra.

En la parte de seguridad web, se realizaron pruebas con SQLMap para analizar vulnerabilidades de inyección SQL en entornos controlados. También se documentó el uso de herramientas orientadas al escaneo de infraestructura, análisis de contraseñas, explotación controlada y evaluación de configuraciones inseguras.

Como resultado, se desarrollaron manuales técnicos de instalación, configuración y uso de las herramientas estudiadas. Estos documentos sirven como material de apoyo para comprender su aplicación práctica y reforzar buenas prácticas relacionadas con hardening, defensa en profundidad y mitigación de riesgos.
