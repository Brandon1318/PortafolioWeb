Gestor de Biblioteca

Este proyecto consistió en el desarrollo de un sistema de escritorio para la gestión de una biblioteca, diseñado para administrar libros, autores, usuarios, préstamos, reservas y devoluciones de manera organizada y eficiente.

La aplicación fue desarrollada en Python utilizando una arquitectura Modelo-Vista-Controlador (MVC), con el objetivo de separar la lógica del sistema, la interfaz gráfica y el acceso a los datos. Esta estructura permitió construir un proyecto más ordenado, mantenible y fácil de ampliar.

El sistema utiliza una base de datos MySQL para almacenar la información bibliográfica y los registros de usuarios. La base de datos fue diseñada considerando relaciones entre libros, autores, préstamos y usuarios, buscando mantener la integridad de la información y evitar redundancias.

Entre sus principales funciones se incluyen el registro y consulta de libros, la gestión de usuarios, el control de préstamos, la validación de disponibilidad de ejemplares y el seguimiento de devoluciones. También se implementaron reglas de negocio para evitar préstamos duplicados y controlar el estado de los materiales.

La interfaz gráfica fue desarrollada con Tkinter, permitiendo una interacción sencilla para administrar los procesos principales de la biblioteca. Además, se integraron componentes como calendarios para facilitar el manejo de fechas relacionadas con préstamos y devoluciones.

Como resultado, el proyecto consolidó una solución funcional para la administración de una biblioteca, reforzando conocimientos en programación orientada a objetos, bases de datos relacionales, arquitectura MVC, validación de datos e interfaces gráficas en Python.

Resultados obtenidos

  • Desarrollo de una aplicación de escritorio para gestión bibliotecaria.
  • Implementación de una arquitectura MVC para organizar el código.
  • Diseño de una base de datos relacional en MySQL.
  • Gestión de libros, autores, usuarios, préstamos y devoluciones.
  • Validación de disponibilidad de ejemplares antes de realizar préstamos.
  • Control de reglas de negocio para evitar registros duplicados o inconsistentes.
