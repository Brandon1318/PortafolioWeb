Red Team vs Blue Team

Implementación de un laboratorio de ciberseguridad en Linux utilizando Kali Linux y Ubuntu Server. Se configuraron servicios vulnerables como SSH, FTP, DNS, HTTP y MySQL para realizar pruebas controladas de reconocimiento, enumeración y fuerza bruta. Posteriormente, se aplicaron medidas defensivas como iptables, Fail2ban, hardening de SSH y monitoreo de logs.

Modelo Predictivo Meteorológico

Desarrollo de un proyecto de análisis y predicción climática desarrollado a partir de datos meteorológicos históricos. El objetivo fue estimar la temperatura media diaria mediante el estudio de variables como temperatura, precipitación, fechas y estaciones meteorológicas, buscando mejorar la precisión de los resultados mediante la evaluación de diversos modelos de machine learning.
